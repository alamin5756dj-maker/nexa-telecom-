NEXA TELECOM — প্রাথমিক PWA প্রোটোটাইপ

ফাইল:
- index.html: ওয়েব অ্যাপের ডিজাইন ও ডেমো ইন্টারঅ্যাকশন
- manifest.webmanifest: PWA ইনস্টল সংক্রান্ত তথ্য
- sw.js: অফলাইন ক্যাশের প্রাথমিক ব্যবস্থা
- icon.svg: অ্যাপ আইকন

চালানোর নিয়ম:
1. ফাইলগুলো একটি HTTPS ওয়েব হোস্টিংয়ে আপলোড করতে হবে।
2. ওয়েবসাইটের HTTPS লিংক Android Chrome-এ খুলতে হবে।
3. Chrome মেনু থেকে "Install app" বা "Add to Home screen" নির্বাচন করতে হবে।

গুরুত্বপূর্ণ:
এটি কেবল ফ্রন্টএন্ড ডেমো। বাস্তব রিচার্জ, পেমেন্ট, OTP, লগইন, ওয়ালেট বা অ্যাডমিন ফাংশন নেই।
এসবের জন্য সার্ভার-সাইড ব্যাকএন্ড, ডাটাবেজ, অনুমোদিত পেমেন্ট গেটওয়ে এবং টেলিকম API প্রয়োজন।
কখনোই API secret বা পেমেন্ট গোপন তথ্য index.html-এ রাখবেন না।

Android APK:
এই PWA-কে পরবর্তীতে Trusted Web Activity/Android wrapper দিয়ে APK-তে প্যাকেজ করা যায়।
এর জন্য HTTPS-এ প্রকাশিত ডোমেইন, Android build setup এবং signing প্রয়োজন।
